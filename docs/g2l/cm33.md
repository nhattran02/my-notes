# Cortex-M33 / remoteproc

The RZ/G2L has a single Cortex-M33 that Linux can start and stop through the
remoteproc framework.

## Build the CM33 firmware

Use the Renesas **RZ/G2L Flexible Software Package (FSP)** or the CM33 sample
projects from the BSP:

```bash
# e.g. the multi-OS package sample
make -C cm33_sample CROSS_COMPILE=arm-none-eabi-
# produces rzg2l_cm33_fw.elf
```

Place the ELF in the rootfs at `/lib/firmware/`.

## Load it from Linux

```bash
echo rzg2l_cm33_fw.elf > /sys/class/remoteproc/remoteproc0/firmware
echo start > /sys/class/remoteproc/remoteproc0/state
# ...
echo stop  > /sys/class/remoteproc/remoteproc0/state
```

Check state and log:

```bash
cat /sys/class/remoteproc/remoteproc0/state
cat /sys/kernel/debug/remoteproc/remoteproc0/trace0
```

## Device tree

The CM33, its SRAM carveout, and the mailbox/IPI must be described and marked
`okay`. Confirm the reserved-memory region does not overlap the Linux DDR map.

## Inter-core communication

- **RPMsg** over the shared vring for message passing.
- **OpenAMP** on the CM33 side.
- Keep the shared buffer region identical in the Linux DT and the CM33 linker
  script.
